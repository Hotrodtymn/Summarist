# Summarist

Summarist is a React 19 book-summary frontend with Firebase, React Router, and an audio-oriented reading experience. Account and content functionality depend on configured services.

## Live site

[Open the deployed website](https://summarist-ebon.vercel.app/)

## Local development

Install Node.js and npm:

```bash
npm install
npm start
```

Visit the local address printed by the development server (typically http://localhost:3000).

## Scripts

- `npm start` — development server
- `npm run build` — production build
- `npm test` — run configured test runner

## Notes

Firebase authentication and book-content functionality require appropriate configuration and service access.
